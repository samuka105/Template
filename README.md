# Padrão Template Method

Exemplo do padrão comportamental **Template Method** aplicado ao cálculo de folha
de pagamento. A classe abstrata define o esqueleto do cálculo do salário líquido
(bruto menos descontos) e da montagem das informações, deixando apenas a regra de
descontos para cada tipo de contratação (CLT, Estagiário, PJ) definir à sua maneira.

## Conteúdo do repositório

- **Código-fonte** do exemplo implementando o padrão Template Method (folha de pagamento).
- **Casos de teste** (JUnit) cobrindo o desconto de cada tipo de contratação e a montagem das informações.
- **Diagrama UML** das classes, em formato de imagem.
